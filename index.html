INTERACTIVE ART / 2026

Untitled

An interactive experiment with lines and motion.

Move, draw and interact.

Controls

01

Draw

左ドラッグで線を描く（Shiftを押しながらで複数線をグループ化）

02

Select

線をクリックして選択する（[ と ] キーで切り替え）

03

Move

右ドラッグで投げる、または十字キーで上下左右に動かす

04

Copy & Paste

Ctrl + C でコピー、Ctrl + V で貼り付け

05

Delete

Backspace / Delete キーで選択中の線を消去する

About

This is an interactive artwork created with JavaScript and p5.js. Draw lines and watch them move around a spherical space.
